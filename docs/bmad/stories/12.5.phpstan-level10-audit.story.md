## Scope funzionale (functional purpose)

This audit ensures **Job module can reach PHPStan Level 10 type safety**, which means:

1. **Proper database querying** - Schedule retrieval, filtering, aggregation are all statically typed
2. **Maintenance operations** - Truncating, deleting, managing failed jobs is properly typed
3. **Dashboard displays** - Statistics widgets use properly typed queries that return Models not stdClass
4. **Test isolation** - Each test can rely on factory type safety without casts
5. **Type inference** - No `mixed` types leaking from model methods

## Error Pattern Analysis (root causes)

### Pattern A: Model instance → Builder methods ✓ FIXED
**Root**: Calling scopes on model instances instead of through query builder
**Fix**: Use `Model::query()->scope()` or `$model->newQuery()->scope()`

### Pattern B: Missing static method type hints ⚠ REMAINING
**Root**: XotBaseModel doesn't declare Eloquent static methods (create, truncate, distinct, count)
**Fix**: Add @method annotations or use Query\Builder alternatives

### Pattern C: Builder union type collapse ⚠ REMAINING
**Root**: Scope methods return `Builder<Model>` but @method declares `Builder<Model>|Model`
**Fix**: Remove union types from @method PHPDoc annotations

### Pattern D: Widget select() → stdClass ⚠ REMAINING
**Files**: JobStatsOverview, JobResourceWidgets
**Root**: `select()` on raw query returns stdClass not Model
**Fix**: Use raw query builder methods, properly cast results or change query approach

### Pattern E: Test factory mixed returns ⚠ REMAINING
**Root**: Model factories generate mixed types when they should return specific Model
**Fix**: Add return type hints to factory methods OR cast in tests

## Technical Decisions Made

1. **Query builder chain pattern**: Always use `Model::query()->scope()->method()` not `$instance->scope()`
   - Rationale: Explicit, type-safe, works with PHPStan's inference
   
2. **Database operations**: Prefer `DB::table()->truncate()` over `Model::truncate()`
   - Rationale: Query\Builder has explicit truncate() method, Eloquent\Builder doesn't
   
3. **@method annotations**: Only return `Builder<static>`, never union with Model
   - Rationale: Static methods return builders, instance methods return models
