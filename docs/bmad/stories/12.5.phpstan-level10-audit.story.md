# 12.5: PHPStan Level 10 audit - fixing 130+ errors across Job module

## Scope funzionale (why this matters)

The Job module has 130+ PHPStan L10 errors blocking full type safety. Errors cluster into **functional areas**:

1. **Get active schedules** (Actions, Services) - fetching filtered schedule records
2. **Job truncation/maintenance** (Filament Pages/Tables) - clearing failed job records
3. **Statistics widgets** (Dashboard) - displaying job counts and metrics
4. **Test factories** (Feature tests) - business logic validation
5. **Query method chaining** (Model scopes) - dynamically building queries

## Error patterns (root causes)

### Pattern A: Model instance → query builder methods
Files: `GetActiveSchedulesAction`, `ScheduleService`
```php
// WRONG: Model instance doesn't have ->get()
$this->model->active()->get()  // $this->model is Schedule instance

// RIGHT: Need query builder first
$this->model->newQuery()->active()->get()
// or: $this->model::query()->active()->get()
```

### Pattern B: Missing static method type hints
Files: All models, all test files
- `Model::create()` returns `mixed` not `Model`
- `Model::truncate()` not recognized as static
- `Model::distinct()`, `Model::count()` not typed

**Root**: XotBaseModel doesn't declare return types for inherited Eloquent static methods

### Pattern C: Builder type union collapse
`Builder<Model>|Model` when only `Builder<Model>` expected
- Calling `->select()` on union type fails
- Calling `->where()` on union type fails

**Root**: Scope methods declared as returning static `Builder` but used on instances

### Pattern D: Widget stats type mismatches  
Files: JobStatsOverview widgets
- `SafeEloquentCastAction::getStringAttribute()` expects Model, gets stdClass
- Translation/label lookups return `array|string`, need `string`

**Root**: Using `select()` raw queries returns stdClass, not Model

## Fix strategy

1. Fix Model instance → Builder (add `->newQuery()` or `->query()`)
2. Ensure scopes work on instances OR use static queries
3. Add explicit return type on Factory `create()` methods
4. Fix widget queries to preserve Model type
5. Fix translation lookups (ensure string not array)
