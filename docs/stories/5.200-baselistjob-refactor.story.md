# Job 5.200 — BaseListJob pattern (9 List Pages refactored)

## Problema

9 Pages nel modulo Job estendevano direttamente `XotBaseListRecords`:
- ListJobs
- ListExports
- ListImports
- ListJobManagers
- ListJobBatches
- ListSchedules
- ListFailedJobs
- ListFailedImportRows
- ListJobsWaiting
- ListJobsWaitings (duplicato)

Assenza di una base class comune violava il pattern BMAD di centralizzazione.

## Soluzione

1. **Creata `BaseListJob.php`** — abstract class che estende `XotBaseListRecords`
   - Namespace: `Modules\Job\Filament\Resources\Pages`
   - Path: `laravel/Modules/Job/app/Filament/Resources/Pages/BaseListJob.php`
   - Scopo: centralizzare hook/configurazione futura comune a tutte le List Pages di Job

2. **Refactor 9 Pages** — estendono ora `BaseListJob` al posto di `XotBaseListRecords`
   - Importa `Modules\Job\Filament\Resources\Pages\BaseListJob`
   - Supporta aggiunta futura di hook/funzionalità comuni senza duplicazione

3. **PHPStan** — 366 file analizzati, 0 errori
