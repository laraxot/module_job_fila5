# Headroom - Modulo Job

Usare la configurazione Headroom comune del progetto quando si lavora su Job.

## Comandi

```bash
headroom mcp status
headroom doctor
headroom savings
headroom perf --hours 24
```

## Regole

- Config canonica: `../../../../../.headroom.yaml`.
- Guida root: `../../../../../docs/HEADROOM-INTEGRATION.md`.
